# Часы работы

В кабинете `/owner` блок **«Часы работы»** позволяет отдельно задать открытие
и закрытие для вс–чт и пт–сб. Время указывается по Москве. Закрытие после
полуночи относится к следующему дню.

По умолчанию: вс–чт **15:00–02:00**, пт–сб **15:00–04:00**.
Настройка хранится в существующей таблице `SiteSetting`, ключ `businessHours`.
Миграция схемы не нужна. Сохранённая настройка переживает перезапуск приложения.

Главная, подвал и schema.org используют одну настройку. Изменение применяется
без пересборки сайта; уже открытые вкладки нужно обновить.

Сохранение: `POST /api/owner/hours`, поля `weekdayOpen`, `weekdayClose`,
`weekendOpen`, `weekendClose` в формате `HH:MM`. Доступ только у владельца
и разработчика, согласно существующей иерархии ролей. Роль проверяется по базе,
источник запроса проверяется сервером, действие записывается в аудит.
